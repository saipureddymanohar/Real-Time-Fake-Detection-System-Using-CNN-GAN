# 🎭 Real-Time Multimodal Deepfake Detection System

AI-powered Deepfake Detection Web Application developed using Python, Flask, TensorFlow, CNN, OpenCV, and Librosa for detecting manipulated audio, image, and video content. The system utilizes Convolutional Neural Networks (CNN) for image classification, MFCC-based audio feature extraction for voice analysis, and OpenCV frame processing for video deepfake detection with real-time prediction capabilities through a secure Flask-based web interface.

# 📝 Abstract

The rapid advancement of artificial intelligence has led to the widespread creation of deepfake images, videos, and synthetic audio, posing serious threats to digital security, privacy, and public trust.

This project proposes a **Real-Time Multimodal Deepfake Detection System** capable of detecting fake content in images, videos, and audio files using CNN, GAN discriminator features, MFCC feature extraction, and LSTM-based audio analysis.

The system provides real-time predictions with confidence scores and supports applications in:
- Digital Forensics
- Cybersecurity
- Media Verification
- Fake Content Classification
